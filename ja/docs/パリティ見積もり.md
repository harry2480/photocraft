# 機能パリティの推定と残りの作業量

PhotoCraft が Adobe Photoshop 2026 にどれだけ近いか、そして Opus 5.5 の作業がどれだけ残っているか。ツールではなく
評価によって作成したものであり、大きな作業の流れが完了したら見直すこと。メニューのカバレッジは `cargo xtask parity` から、
忠実度は PSD オラクル（`cargo xtask corpus` / `oracle_diff`）から得ている。

## 要点

> **2026-10-03 更新：** メニュー／コマンドの網羅率は **100%（625/625）** に到達した。Photoshop の
> すべてのメニュー項目が実際に動作するコマンドをディスパッチするようになった（Variables/Data Sets、Trap、タイムラインパネル、
> レイヤー › ビデオレイヤーを含む）。残るパリティ作業は網羅性ではなく深さと忠実度である：PSD オラクル
> （約 66%）、Camera Raw／ビデオレイヤーの深さ、そして AI/Neural 層。下の表を参照。


- **メニュー／コマンドの網羅率：** Photoshop のメニュー項目 625 / 625 が動作 = **100%**（すべてのメニュー項目に動作するコマンドがある）。
- **PSD レンダリング忠実度（オラクル）：** コーパス 170 ファイル中 約 111 がピクセル一致 = **約 65%**。
- **全体の機能パリティ（加重、主流のワークフロー）：** **約 86%**（メニューの網羅は完了。深さと忠実度が残りの差）。
- **Adobe の AI / Firefly 機能を含めた全体：** **約 75%**（これらの大半はクラウド／ML であり、
  クリーンルームで到達するのが最も難しい）。

メニューのカバレッジ（96%）は真のパリティを過大評価している。多くの動作するコマンドが、忠実ではあるが近似的だからである
（マスキング／キャリブレーションのない Camera Raw、UI のない Vanishing Point、Adobe の ML に対するヒューリスティックな
Select Subject/Sky、基本的な Content-Aware Fill）。加重値は、単なる有無ではなく深さと忠実度を考慮している。

## 領域別の現状

| 領域 | パリティ | 備考 |
|---|---:|---|
| レイヤー、マスク、グループ、描画モード、スマートオブジェクト、レイヤースタイル | 約 92% | 幅広く GPU アクセラレーション済み。ベベル／サテンの形状といくつかの描画モードのエッジケースが残る |
| 選択範囲、パス、ベクトルシェイプ、ペン | 約 90% | 選択範囲メニューは項目の 100%。Select Subject/Sky は ML ではなくヒューリスティック |
| ペイント／ブラシエンジン、レタッチ（コピースタンプ、修復） | 約 85% | 堅実。混合ブラシの深さがなく、コンテンツに応じた修復もない |
| 色調補正 + 調整レイヤー | 約 90% | 全種類あり。Camera Raw の深さといくつかのトーカーブモデルは近似 |
| フィルター（フィルターギャラリー ×47、ゆがみ、ぼかし、描画を含む） | 約 88% | ギャラリーの見た目は近似。ニューラルフィルターなし |
| 文字／テキストエンジン、文字・段落スタイル、字形 | 約 90% | 縦書きと OpenType の異体字が手薄 |

| ファイル I/O：PSD、ネイティブ .pcraft、フラット形式（png/jpg/tiff/webp/exr/…） | 約 85% | PSD オラクルは約 65% がピクセル一致。構造の大半はラウンドトリップする |

| コンピュテーショナルフォト（Photomerge、HDR、レンズ、Camera Raw、Wide Angle） | 約 70% | 古典的な実装。汎用のレンズプロファイルのみ |
| データ駆動グラフィック（Variables、Data Sets） | 約 0% | 未着手（メニュー項目 5 つ） |
| ビデオ／タイムライン／アニメーション | 約 0% | 未着手（メニュー項目 13 個）— サブシステム 1 つ分 |
| AI / Neural / 生成（Firefly、Sensei、ニューラルフィルター） | 約 5% | ほぼ存在しない。ライセンスされた／学習済みのモデルが必要 |
| プリプレスのニッチ機能（Trap、計測スケールのプロ機能） | 約 30% | Trap、インクの広がりはモデル化されていない |

## 残り 25 のメニュー項目（グループ別）

- **ビデオとタイムライン（13）：** ビデオレイヤー（新規／挿入／複製／削除／置き換え／解釈／復元／
  再読み込み／ラスタライズ）、ラスタライズ › ビデオ、タイムラインパネル、ビデオをレンダリング、ビデオフレームからレイヤー。
  まとまった 1 つのサブシステム：フレーム／時間モデル、ビデオのデコーダー／エンコーダー（クリーンルームの Rust、ffmpeg なし）、
  オニオンスキン、タイムライン UI。
- **データ駆動グラフィック（5）：** 変数 › 定義 / データセット、データセットを適用、データセットをファイルとして書き出し、
  変数データセットを読み込み。レイヤー上のテンプレートバインディングモデル + CSV／データセットのエンジン。
- **ニッチ／プラットフォーム（7）：** Trap（プリプレスのインクの広がり）、レイヤーからフレームを作成、プリセットを移行、WIA
  サポート（Windows のスキャナー）、および既に隣接している 2 項目。

## パリティまでの作業量（Opus 5.5）

2 つの時計：**エージェント時間**（モデルの総作業量）と **実時間**（このセッションで観測した、独立した作業の流れ間での
約 6–8 倍の並列度を考慮）。このセッションでは 8 つの並列エージェントを使い、数時間の実時間で約 70 のメニュー項目と主要なサブシステムを
投入したので、実時間 ≈ エージェント時間 ÷ 6 とする。

| マイルストーン | 範囲 | エージェント時間 | 実時間 |
|---|---|---:|---:|
| **機能 90% まで** | AI／ビデオ以外の残りのメニュー項目（Variables、Trap、Frame、Migrate、WIA）、Camera Raw の深さ、Vanishing Point の UI、選択の品質、仕上げ | 60–90 | 10–15 時間 |
| **機能 95% まで** | 上記 + PSD オラクル 65% → 約 90%（ベベル／サテンの形状、Lab ブレンド、ノイズグラデーションの乱数生成器、トーカーブ）、UI パリティの全面的な見直し、性能の見直し | +80–130 | +15–22 時間 |
| **ビデオ／タイムラインのサブシステム** | フレームモデル、クリーンルームのデコード／エンコード、タイムライン、アニメーション、ビデオをレンダリング | 50–80 | 10–14 時間 |
| **信頼に足る AI 層** | ML による Select Subject/Sky、Content-Aware Fill（PatchMatch++）、基本的な生成塗りつぶし／生成拡張 — モデルの統合が必要。ライセンスされたモデルなしでは、完全なクリーンルームで実現不可能な機能もありうる | 120–250+ | 25–45 時間 |

**合計：**
- **約 95% の機能パリティ**（ビデオと AI 以外のすべて）まで：並列エージェントによる Opus 5.5 で **約 140–220 エージェント時間 ≈ 25–40
  実時間**。
- ビデオのサブシステムを含めた **約 98%** まで：**+50–80 エージェント時間 ≈ +10–14 実時間**。
- 信頼に足る AI 層を含めた **約 99%** まで：**+120–250 エージェント時間 ≈ +25–45 実時間**。ただし、
  Firefly/Sensei とのピクセル単位のパリティは、学習済みモデルなしのクリーンルームでは達成できないという
  留意点がある。目指すのは機能的な同等物である。

**最良の単一の数値：** PhotoCraft は Photoshop の完全なパリティに向けて **約 82% の地点** にあり、
**95%、大半のユーザーに出荷できる** 状態に到達するには、並列の Opus 5.5 の作業でおよそ **25–40 実時間** かかる。
最後の 5%（ビデオ + AI）を埋めるのは、長く不確実なロングテールである。

## 前提と留意点

- 「パリティ」= バイト単位で同一の出力ではなく、ユーザーができることの機能面と見た目の同等性。クリーン
  ルームとは、Adobe のコード、プロファイル、シェーダー、学習済みモデルを使わないことを意味する。AI 機能は同等物を目指す。
- 実時間は、このセッションと同様に、それぞれ独自のターゲットディレクトリを持つ 6–8 の独立した作業の流れが並列に進むことを前提とする。
  逐次作業では約 6 倍長くなる。
- Adobe は Photoshop から 3D/Substance を削除したため、3D は意図的に対象外とする。
- 忠実度の時間が最も不確実である：残るオラクルの失敗は、プロプライエタリな乱数生成器と、
  観察によって当てはめた未公開のカーブモデルによるものである。
