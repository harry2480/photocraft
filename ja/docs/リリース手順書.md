# リリースプレイブック

すべての Crafting App で共有するリリースプレイブックは craftrules にある:
[`../craftrules/release/playbook.md`](../../craftrules/release/playbook.md)
（`storytold/craftrules`）。こちらが正本であり、ここに複製しないこと。

PhotoCraft はその参照実装である（`.github/workflows/release.yml`、`packaging/`、
`cargo xtask version`）。PhotoCraft 固有の詳細は [releasing.md](リリース.md) にある。
