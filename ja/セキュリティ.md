# セキュリティポリシー

PhotoCraft は複雑なドキュメント形式や画像形式を処理し、CLI、JSON コントロール、MCP による自動操作を公開しています。ファイル、パス、メタデータ、自動操作のリクエスト、コマンドパラメーターは、悪意のあるものである可能性があるものとして扱ってください。

## 脆弱性の報告

悪用可能な詳細、概念実証コード、攻撃用に細工したファイルを公開する前に、リポジトリのメンテナーが調査し修正を調整するための妥当な機会を与えてください。

このリポジトリでは現在、専用の非公開セキュリティ用メールアドレスや非公開の報告窓口を記載していません。プロジェクトにすでに記載されているリポジトリのオーナー/メンテナーの連絡手段を通じてメンテナーに連絡し、公開の場では悪用できない最小限の概要のみを伝え、機微な詳細を共有する前に適切な非公開の受け渡し方法を相談してください。動作するエクスプロイト、シークレット、機微なクラッシュダンプ、悪意のある添付ファイルを含む公開 Issue は作成しないでください。

非公開の連絡手段を確立できない場合は、攻撃用の資料は渡さず、メンテナーが連絡を取れる程度の、安全で最小限の説明のみを報告してください。

## 報告に含める内容

有用な報告には次の内容が含まれます。

- 影響を受ける PhotoCraft のバージョン、コミット、またはリリース成果物
- OS、アーキテクチャ、ビルドプロファイル、関連する feature フラグ
- 影響を受けるコンポーネントまたはパス
- セキュリティ上の影響と、攻撃者に必要なアクセス
- 正確な再現手順
- 期待される動作と実際の動作
- 該当する場合はクラッシュログ、バックトレース、サニタイザーの出力、リソース使用量の計測値
- クリーンなチェックアウトから再現するかどうか
- 既知の回避策や影響を封じ込める方法

ログからは、認証情報、個人的なパス、非公開のドキュメント内容、無関係なシステム情報を取り除いてください。

## 悪意のあるテストファイル

有害となりうるファイルや再配布できないファイルを公開 Issue に添付しないでください。まずは、その形式、サイズ、暗号学的ハッシュ、観測された影響、出所の区分（例: 合成したもの、ファジングで生成したもの）、問題を再現するためのコマンドを伝えてください。サンプルを送る前に、メンテナーと非公開の受け渡し方法を調整してください。

リポジトリに受け入れるテストファイルは、最小化され、個人データやプロプライエタリなデータを含まず、法的に再配布可能で、期待される失敗時の動作が文書化されている必要があります。修正したパーサーの欠陥には、安全かつ実用的である限り、恒久的な回帰テストを追加してください。

## 対象範囲

セキュリティ報告の対象には次のものが含まれます。

- PSD/PSB、ラスター、`.pcraft`、ICC、LUT、パターン、埋め込みオブジェクトのパース
- 解凍爆弾、過大な寸法、整数オーバーフロー、メモリ枯渇、再帰、ハング
- 読み込み/書き出しとファイルシステムのパス処理（トラバーサル、シンボリックリンク、安全でない上書き動作を含む）
- エンジンのコマンド検証とシリアライズ/デシリアライズ
- デスクトップのコントロールサーバー、ヘッドレス JSON サーバー、MCP サーバー、MCP から GUI へのブリッジ
- 認証、認可/ケイパビリティ、リクエスト制限、バッチ制限、接続の枯渇
- GPU リソースの検証やドライバーに渡る入力の処理
- 依存関係、CI、パッケージング、署名、チェックサム、リリース成果物の完全性

セキュリティ上の影響がない一般的なバグは、プロジェクトの通常の Issue およびコントリビューションの手順を使ってください。

## 現在の制限事項

TCP コントロール接続では、メソッドのディスパッチ前に 256 ビットのベアラートークンが必要であり、リクエスト行、アクティブ接続数、バッチのステップ数に制限を設けています。これらの保護はケイパビリティモデルを提供するものではなく、認証済みのクライアントは公開されているコントロール機能のすべてを利用できます。自動操作によるファイル操作は設定されたワークスペースのルートに制限されておらず、JSON の深さ、レンダリング、ドキュメントのメモリ、コマンドの実行時間、クライアントの識別、暗号化、監査に関する制御はまだ実装されていません。ソースに基づく現状と堅牢化のロードマップについては、[セキュリティドキュメント](book/src/security/概要.md)を参照してください。
