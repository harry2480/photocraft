# セキュリティの概要

PhotoCraft は攻撃者が制御しうる複雑なファイルを処理し、ユーザーのファイルシステム権限で動作しうる自動操作を公開している。そのため、セキュリティはパーサー、エンジン、I/O、自動操作、リリース、依存関係の設計の一部である。

## 現在の状況

| 領域 | 実装済みの保護 | 既知の制限事項 / 今後の課題 |
|---|---|---|
| PSD/PSB | ヘッダー、チャンネル、デコード後のバイト数、ネスト、パターンの制限。不正形式/プロパティテスト。ファズターゲット | より広範な敵対的コーパス、合計の処理予算、埋め込みオブジェクトのカバレッジ |
| ラスターコーデック | 寸法/ピクセル数/アロケーションのデフォルト制限。デコーダー固有の予算。不正形式/プロパティテスト。ファズターゲット | 継続的なファジングと、フォーマット固有のセマンティクスに関するケースの拡充 |
| `.pcraft` | マニフェスト/blob/合計バイト数の制限。上限付きの展開。CRC/ハッシュおよびバージョンのチェック。ファズターゲット | 複雑さ/エントリ数の制限の厳格化と、ディレクトリバンドルのパス競合の分析 |
| エンジンコマンド | エラーを返す契約、不正パラメーターに焦点を当てたテスト、敵対的な `panic_hunt` テスト | 入力に起因するパニックや枯渇の経路の除去を継続 |
| コントロール TCP | ループバックへのバインド。ベアラートークン認証。ルートに限定された読み取り/書き込み権限。1 MiB のリクエスト行。8 MiB の応答。アクティブ接続 16。I/O タイムアウト | 汎用的なメソッドケイパビリティ、暗号化、クライアントの識別、JSON の深さに関する明示的なポリシー、セッションのメモリ合計/コマンド実行時間の予算、監査証跡がない |
| MCP | stdio。型付きツール。認証済みで上限付きのブリッジ。ルートに限定された読み取り/書き込み権限。合計の応答予算付きの 256 ステップのバッチ。ヘッドレスのプレビュー/出力の上限 | 汎用的なツール認可スコープ、セッションのメモリ合計の計上、コマンドのキャンセルがない。トランスポートの応答上限はデスクトップのスクリーンショット取得を制限しない |
| 依存関係 | Cargo のロックファイルと、通常の CI によるビルド/テスト/clippy | 現在のツリーでは `cargo-audit` や `cargo-deny` のジョブ/設定は確認されていない |
| リリース | シークレットが設定されている場合のチェックサムと、プラットフォームごとの署名/公証の経路 | 署名がない場合がある。現在のツリーでは SBOM の生成は確認されていない |

この表は現在のリポジトリのスナップショットであり、デプロイされた成果物についての保証ではない。高リスクな用途では、ソースとリリースの証拠を検証すること。

## セキュリティの優先事項

1. 認証済みトランスポートの上に、ケイパビリティでスコープを限定した自動操作セッションを追加する。
2. ファイルを扱うコマンドが進化しても、実装済みのワークスペースハンドルの境界を維持する。
3. プレビュー/応答の予算を、JSON の複雑さ、ドキュメント/セッションのメモリ合計、デスクトップの
   取得/読み込み/書き出し、コマンドの実行時間/キャンセルにまで拡張する。
4. PSD/PSB、コーデック、`.pcraft` のファジングを回帰用コーパスとともに拡充する。
5. 依存関係のアドバイザリ/ライセンスのポリシーチェックと、リリースの SBOM を追加する。

まず[脅威モデル](脅威モデル.md)を読み、その後、ファイル処理、パーサー、ファジング、自動操作についての個別のページを参照すること。
