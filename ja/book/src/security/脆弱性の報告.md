# 脆弱性の報告

リポジトリ直下の [`SECURITY.md`](https://github.com/storytold/photocraft/blob/main/SECURITY.md) が正式な報告ポリシーである。

メンテナーがレビューして修正を調整するための妥当な機会を得る前に、エクスプロイトの詳細、攻撃用に細工したファイル、シークレット、機微なクラッシュデータを公開しないこと。リポジトリには現在、専用の非公開セキュリティ用メールアドレスや非公開の報告先は記載されていない。

有用な報告には、影響を受けるバージョンまたはコミット、プラットフォーム/ビルド構成、影響、正確な再現手順、期待される動作と実際の動作、関連するログやバックトレースが含まれる。悪意のあるテストファイルについては、まず最小限の説明、ハッシュ、形式、安全な受け渡しの要件を伝えること。ユーザーに害を与えうる場合や再配布できないデータを含む場合は、公開の場に添付しないこと。

セキュリティの対象範囲には、パーサー、読み込み/書き出し、`.pcraft`、プロファイル/LUT/パターン、コマンドの検証、自動操作、MCP、コントロールサーバー、パスの処理、GPU リソースの検証、依存関係、CI、パッケージング、アップデート、成果物の検証が含まれる。
