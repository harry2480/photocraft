# 脅威モデル

この脅威モデルは、ソースリポジトリのデスクトップ、CLI、WebAssembly、フォーマット、自動操作の各領域を対象とする。ファイル、パス、JSON、MCP メッセージ、エージェントの判断、埋め込みメタデータは悪意のあるものでありうると想定する。

## 保護対象の資産

- ユーザーのドキュメント、メタデータ、認証情報、無関係なローカルファイルの機密性
- ドキュメント、環境設定、ファイルシステムの内容、アプリケーション状態の完全性
- PhotoCraft およびホストシステムの可用性
- リリース成果物と依存関係の完全性および出所
- 予測可能なコマンド実行とドキュメントの忠実性

## 脅威アクター

- 悪意のある画像、PSD/PSB、`.pcraft`、プロファイル、LUT、パターン、埋め込みオブジェクトの作成者
- ループバックサーバーに接続する、悪意のある、または侵害されたローカルプロセス
- 悪意のある、侵害された、または過剰な権限を持つ MCP クライアントや自動操作エージェント
- 安全でないパスや高コストなコマンドを誘発するプロジェクト/アクションファイル
- 侵害された依存関係、またはビルド/リリース環境

## 侵入口

```text
untrusted files and bytes
  PSD / PSB / raster / .pcraft / ICC / LUT / pattern / embedded content

untrusted control data
  CLI arguments / filesystem paths / JSON-lines / MCP requests / agent commands

untrusted build inputs
  dependencies / CI actions / release secrets / packaging tools
```

## 主な脅威シナリオ

### 敵対的なドキュメントのパース

小さなファイルが、過大な寸法、過剰なチャンネル数、ネストしたディスクリプター、破損したオフセット、あるいは極端に展開される圧縮データを宣言する。望ましい結果は、不合理なアロケーションや処理の前にそれを拒否し、エラーを返し、最小化した回帰テストを残すことである。

### ファイルシステム権限の悪用

自動操作クライアントが、絶対パス、トラバーサルのシーケンス、シンボリックリンク、ジャンクション、または差し替えられたパスを与え、意図したプロジェクト外のデータを読み取ったり上書きしたりする。現在の自動操作は呼び出し元が与えた OS パスを使い、ワークスペースのポリシーを持たない。このシナリオは既知の制限事項である。

### ローカルでのコントロール乗っ取り

同じホスト上の別のプロセスがループバックのコントロールサーバーに接続し、メソッドを探索し、UI 入力を操作し、コマンドを実行し、ファイルを開いたり保存したりする。ループバックはネットワークへの露出を減らすが、クライアントを認証するものではない。

### リソース枯渇

クライアントが大量の TCP 接続を開く、極端に長い JSON 行を送る、巨大なバッチを作る、フルサイズのレンダリングを要求する、または高コストなコマンドを繰り返し呼び出す。現在の自動操作トランスポートには、リクエスト、バッチ、接続についての明示的な予算がない。

### サプライチェーンの侵害

脆弱な、または悪意のあるクレート、アクション、インストーラーツール、署名環境が、ビルドの挙動や成果物を改変する。ロックファイルとリリースのチェックサムは再現性と検証に役立つが、アドバイザリ/ライセンスのポリシーチェックと SBOM の出力は今後の課題である。

## セキュリティ目標

- 可能な限りアロケーションの前に、不正な形式のデータや過大なデータを拒否する。
- パーサー/コマンドの境界で、チェック付き算術演算と上限付きの再帰を使う。
- 自動操作の権限を明示的で、狭く、取り消し可能なものにする。
- トラバーサルやリンクの小細工があっても、ファイルアクセスを許可されたルート内にとどめる。
- リクエストごと、セッションごとに処理量の上限を設ける。
- 自動操作の動作を調査するのに十分な、シークレットを含まない監査データを保持する。
- 修正したセキュリティバグはすべて恒久的な回帰テストにする。

## 対象外と限界

PhotoCraft は現在、敵対的な自動操作や敵対的なネイティブコードに対するサンドボックスではない。ループバックのトランスポート、Rust のメモリ安全性、型付きスキーマ、ファイル形式のチェックは、認証、認可、OS による隔離、運用上の最小権限の代わりにはならない。本ドキュメントは、これらの欠けている制御が存在すると主張するものではない。
