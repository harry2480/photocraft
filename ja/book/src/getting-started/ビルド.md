# ビルド

PhotoCraft はリポジトリのルートにある Rust ワークスペースを使用します。安定版の Rust ツールチェーンをインストールし、リポジトリをクローンして、ルートからコマンドを実行してください。

```sh
cargo build --workspace
cargo run --release -p photocraft -- image.psd
cargo run -p photocraft-cli -- --help
```

リポジトリの標準ゲートは次のとおりです。

```sh
cargo fmt --all -- --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo xtask layers
cargo xtask wasm
```

`cargo xtask wasm` には `wasm32-unknown-unknown` ターゲットが必要です。UI に関する作業は、[開発ガイド](https://github.com/storytold/photocraft/blob/main/docs/development.md) で説明されているオフスクリーンのスナップショット例でも確認してください。

## ドキュメントのビルド

mdBook をインストールし、リポジトリのルートからビルドします。

```sh
cargo install mdbook --locked
mdbook build book
```

生成されたサイトは `book/output/` に書き出されます。これはソースドキュメントではありません。
