# インストール

PhotoCraft は現在、初期アルファ段階のプロジェクトです。リリース成果物は、利用可能になった時点でリポジトリの GitHub Releases ページで公開されます。ダウンロードした成果物を実行する前に、リリースノートとチェックサムを確認してください。

ソースからビルドする場合は [ビルド](ビルド.md) に進んでください。デスクトップアプリケーション、ヘッドレス CLI、Web ターゲットは、それぞれ独立したワークスペースアプリケーションです。

- `apps/photocraft`: ネイティブのデスクトップアプリケーション
- `apps/photocraft-cli`: ヘッドレス CLI、JSON-lines サーバー、MCP サーバー
- `apps/photocraft-web`: Trunk でビルドされる WebAssembly アプリケーション

プラットフォームごとのパッケージングと署名の詳細は、既存の [リリースドキュメント](https://github.com/storytold/photocraft/blob/main/docs/releasing.md) で管理されています。署名は設定されたリリース用シークレットの有無に依存するため、成果物が存在するだけでは署名済みであることの証明になりません。

## 入力ファイルの信頼性

PSD、PSB、`.pcraft`、ラスター画像、プロファイル、LUT、パターン、およびドキュメントに埋め込まれたコンテンツは、悪意のある可能性があるものとして扱ってください。権限の高い環境や機密性の高い環境で出所不明のファイルを使う前に、[安全なファイル処理](../security/安全なファイル処理.md) を確認してください。
