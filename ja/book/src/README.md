# PhotoCraft ドキュメント

PhotoCraft は Rust で書かれたネイティブ画像エディタです。このブックは、インストール、アーキテクチャ、フォーマット、自動化、開発、セキュリティに関するドキュメントの、継続的にメンテナンスされる入口です。

詳細な設計メモ、パリティレポート、UI 規約、リリース手順、および制御プロトコルの完全なメソッドリファレンスについては、リポジトリの既存の `docs/` ディレクトリが引き続き正となります。このブックはそれらを複製せず、リンクで参照します。

- ユーザー・評価者: [インストール](getting-started/インストール.md)
- コントリビューター: [ビルド](getting-started/ビルド.md) と [コントリビューション](getting-started/コントリビューション.md)

## コーディングエージェント向けドキュメント

コーディングエージェントは次の順序で読んでください。

1. リポジトリのルールと検証ゲートについては [`AGENTS.md`](https://github.com/storytold/photocraft/blob/main/AGENTS.md)。
2. プロダクトのスコープと現在のエントリポイントについては [`README.md`](https://github.com/storytold/photocraft/blob/main/README.md)。
3. クレートの境界とコマンドの流れについては [`book/src/architecture/`](architecture/概要.md)。
4. CLI、制御プロトコル、MCP サーバーを操作する前に [`book/src/automation/`](automation/概要.md)。
5. パーサー、ファイル I/O、自動化、MCP、制御サーバー、コマンド実行、シリアライズ／デシリアライズを変更する前に [`book/src/security/`](security/概要.md)。

エージェントは、ドキュメントのバイト列、パス、コマンドパラメータ、自動化メッセージを信頼できない入力として扱わなければなりません。ある制御策の提案を説明するページがあっても、その制御策が実装済みであるとは限りません。

## ステータスの表記

セキュリティ関連のページでは、次の 4 つのラベルを一貫して使用します。

- **Implemented（実装済み）:** 現行のソースまたはテストで確認された挙動。
- **Known limitation（既知の制限）:** 現行のソースに存在するリスク、または欠けている制御策。
- **Proposed（提案）:** 現行ビルドでは強制されていない設計の方向性。
- **Future hardening（今後の強化）:** 有用だが、まだ実装が承認されていないフォローアップ作業。
