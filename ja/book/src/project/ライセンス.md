# ライセンス

PhotoCraft のソースは、利用者の選択により MIT または Apache-2.0 のデュアルライセンスで提供されています。正式な条項はリポジトリ内の次のファイルです。

- [`LICENSE-MIT`](https://github.com/storytold/photocraft/blob/main/LICENSE-MIT)
- [`LICENSE-APACHE`](https://github.com/storytold/photocraft/blob/main/LICENSE-APACHE)
- [`NOTICE`](https://github.com/storytold/photocraft/blob/main/NOTICE)
- [`ATTRIBUTION.md`](https://github.com/storytold/photocraft/blob/main/ATTRIBUTION.md)

同梱されているサードパーティのアセットは、それぞれ固有のライセンスと帰属表示の要件を保持します。`docs/brand/` にある ArtCraft の名称、ワードマーク、ロゴは [`docs/brand/LICENSE-brand.txt`](https://github.com/storytold/photocraft/blob/main/docs/brand/LICENSE-brand.txt) に従い、ソースコードのライセンスの対象外です。

このページはリポジトリ内の所在をまとめたものであり、所有権やライセンスの条項を変更するものではありません。
