# ロードマップ

最新のプロダクトロードマップ、マイルストーンの定義、パリティの計測値、現在のフォーカスは [`docs/roadmap.md`](https://github.com/storytold/photocraft/blob/main/docs/roadmap.md) で管理されています。メニューのカバレッジは `cargo xtask parity` によって [`docs/parity.md`](https://github.com/storytold/photocraft/blob/main/docs/parity.md) に生成されます。

セキュリティの強化は分野横断的な取り組みであり、これらのプロダクトのマイルストーンを置き換えるものではありません。現在のセキュリティ強化の順序は次のとおりです。

1. 脅威モデルと報告ポリシー
2. 認証付きの制御セッション
3. ケイパビリティでスコープされた MCP／制御アクセス
4. ワークスペースをルートとするファイルシステムハンドル
5. リクエスト、バッチ、レンダリング、接続の予算
6. より広範なパーサーのファジングと悪意ある入力の回帰コーパス
7. 依存関係ポリシーとリリースの SBOM／プロベナンス

このブックによって確立されたのは、項目 1 のドキュメント基盤のみです。それ以降の制御策は、実装されテストされるまで提案段階のままです。
