# クレジット

PhotoCraft は ArtCraft チームと PhotoCraft のコントリビューターによって作成・メンテナンスされています。プロジェクトの所有権、著作権、ライセンスは、リポジトリの `README.md`、`NOTICE`、およびライセンスファイルに記載されたとおりです。マージされたすべてのコントリビューションは、リポジトリの履歴とリリースノートでクレジットされます。

## ドキュメント

- [Gh0stlyKn1ght](https://github.com/Gh0stlyKn1ght): 最初のドキュメントブックと、そのセキュリティドキュメント（脅威モデル、信頼境界、パーサーの堅牢化とファジングに関するメモ、脆弱性報告のガイダンス）。
