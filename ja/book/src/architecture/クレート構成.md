# クレートと依存レイヤー

以下のレイヤー番号は、許可される依存の方向を表すものであり、実行時の権限を表すものではない。クレートは自身より下位のレイヤーにのみ依存できる。スタンドアロンのフォーマットクレートは、指定されている場合、他のワークスペースクレートから独立したままである。

| レイヤー | クレート | 責務 |
|---|---|---|
| L0 | `geom`, `cms`, `color`, `raster` | ジオメトリ、ICC 処理、色／ブレンド演算、ピクセルフォーマット、コピーオンライトのタイル |
| L0 スタンドアロン | `psd`, `codecs` | PSD/PSB およびフラットなラスターフォーマットの解析／エンコード |
| L1 | `doc` | 純粋データとしてのドキュメント、レイヤー、マスク、エフェクト、調整、テキスト、ベクター、スマートオブジェクト |
| L2 | `ops`, `paint`, `algo`, `text`, `vector` | ヒストリー操作、ペイント、画像処理アルゴリズム、文字、パス、シェイプ |
| L3 | `compose`, `gpu`, `format` | CPU 合成、wgpu 合成、`.pcraft` の永続化 |
| L4 | `io` | ドキュメントモデルと外部フォーマット間のインポート／エクスポート |
| L5 | `engine` | `Session`、コマンドレジストリ、検証、ヒストリー統合、検査 |
| L6 | `ui-egui`, `automation` | egui シェル、ヘッドレス自動化、MCP、ライブブリッジ |
| テスト支援 | `testkit` | 共有テストヘルパー |

ワークスペースのアプリケーションは次のとおり。

| アプリケーション | パス | 用途 |
|---|---|---|
| PhotoCraft デスクトップ | `apps/photocraft` | eframe/wgpu アプリケーションとループバック制御サーバー |
| PhotoCraft CLI | `apps/photocraft-cli` | 変換、検査、実行、バッチ、JSON-lines serve、MCP |
| PhotoCraft Web | `apps/photocraft-web` | WebAssembly 向けにコンパイルされた UI とエンジン |

新しいクレートは `xtask/src/layers.rs` に登録しなければならない。`ui-egui` より下位のものは egui、eframe、winit、rfd に依存してはならない。`psd`、`codecs`、`cms` クレートには、[`AGENTS.md`](https://github.com/storytold/photocraft/blob/main/AGENTS.md) に記載された追加の独立性要件がある。
