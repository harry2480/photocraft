# フォーマットの概要

外部のバイト列は、主に 3 つの経路から PhotoCraft に入る。

- `photocraft-psd` は PSD および PSB の構造を解析・書き出しする。
- `photocraft-codecs` はフラットなラスターフォーマットをデコード・エンコードする。
- `photocraft-format` はネイティブの `.pcraft` バンドルを読み込み・保存する。

`photocraft-io` は PSD とフラットな画像をドキュメントモデルへ対応付け、ドキュメントをそれらのフォーマットへエクスポートし直す。これは統合層であり、解析時の制限は引き続き下位のフォーマットクレートの責任である。

フォーマットは主要なセキュリティ境界である。ファイル拡張子は信頼のシグナルにならず、メタデータは攻撃者が制御しうるものであり、小さな圧縮入力が非常に大きなデコード出力を宣言することもある。呼び出し側は制限付きのデフォルト API を使い、無制限の設定で再試行するのではなくエラーをそのまま扱うべきである。

[PSD と PSB](PSD・PSB形式.md)、[ラスターフォーマット](ラスター形式.md)、[`.pcraft` フォーマット](pcraft形式.md) を参照のこと。フォーマット横断の堅牢化の指針は [パーサーの堅牢化](../security/パーサーの堅牢化.md) にある。
