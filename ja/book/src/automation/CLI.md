# コマンドラインインターフェース

`apps/photocraft-cli` は現在、次のサブコマンドを提供している。

| コマンド | 用途 |
|---|---|
| `convert` | ドキュメントを 1 つ開き、別のフォーマットへエクスポートする |
| `info` | ドキュメントのサイズ、モード、ビット深度、レイヤー情報を JSON で出力する |
| `run` | ドキュメントを開くか新規作成し、エンジンコマンドを実行し、必要に応じて保存する |
| `batch` | 1 つの入力ディレクトリ内のファイルにアクションリストを適用する |
| `droplet` | ファイルまたはフォルダに対して PhotoCraft ドロップレットを実行する |
| `commands` | コマンド ID とパラメータのドキュメントを一覧表示する |
| `mcp` | stdio 上で MCP サーバーを起動する（デスクトップアプリへのブリッジも可能） |
| `serve` | stdio またはループバック TCP 上で JSON-lines ヘッドレスサーバーを起動する |

実行可能ファイルとしての正は `photocraft-cli --help` である。範囲の限定された典型的なコマンド実行は次のとおり。

```sh
photocraft-cli run input.psd \
  --cmd image.adjustments.invert \
  --out output.png
```

現行の CLI に渡されるパスは通常の OS パスである。CLI はそれらをワークスペースのルート配下に制限しない。バッチ出力は指定された出力ディレクトリを作成し、保存操作は親ディレクトリを作成することがある。信頼できないアクションファイルは、適切に分離されたアカウントまたは環境でのみ実行すること。

CLI の解析は不正なフラグや JSON をエラーとして報告するが、セキュリティポリシーの層ではない。各エンジンコマンドは引き続き自身のパラメータを検証する責任を負う。
